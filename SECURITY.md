# Security

This is a portfolio repository. Security is treated as “secure-by-default documentation” rather than production hardening.

## What is included
- `.env.example` only (no secrets committed)
- sample logs are sanitised and contain no credentials

## What is intentionally excluded
- real credentials / API keys
- real member details (PII)
- production deployment configuration

## If you run locally
- keep your local `.env` out of version control
- do not paste real library member data into the raw data folders
