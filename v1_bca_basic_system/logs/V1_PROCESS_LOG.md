# v1 Process Log

## Purpose
Demonstrate a realistic baseline system: books, members, issue/return, fines, and exports.

## Operational flow
1. Add/update books
2. Add/update members
3. Issue a book (validate stock)
4. Return a book (calculate fine if overdue)
5. Export evidence CSVs
