# Privacy

## Scope
This project models a typical library workflow (inventory + issue/return).  
To remain portfolio-safe, **all data in this repo is synthetic**.

## Controls
- no real member identities
- no real borrowing history
- no real addresses / phone / email

## Guidance
If you adapt this project for a real environment:
- implement access control and audit trails
- follow local data protection policies
- separate operational data from analytics datasets
