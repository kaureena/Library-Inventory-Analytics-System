# Evidence Packs

This folder contains screenshot-style evidence grouped by area:

- `v1_ui/` — baseline UI screenshots (subset/collage for quick review)
- `v2_pipeline/` — staged/curated previews, run register, DQ summary
- `v2_bi/` — dashboard page collages + KPI definition screenshots
- `diagrams/` — diagram gallery for architecture/star schema/DQ flow

Each evidence file is named:
`evidence_XX_<short_description>.png`
